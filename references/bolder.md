# Bolder Mode

Amplifies safe or bland designs. Makes existing design language more decisive and committed, not chaotic.

## Process

1. **Assess current state.** What's weak? What's safe to the point of forgettable?
2. **Lock to design system.** Stay within existing tokens. Do not invent new ones.
3. **Plan amplification.** Pick one focal point to push hardest. Use existing system levers (color, type, spacing, motion) to amplify.

## Amplification Levers

### Color
- Push the primary color higher on the commitment axis (Restrained -> Committed -> Full Palette)
- Use the brand color at larger surface areas
- Increase contrast between foreground and background
- Add a deliberate accent that draws the eye

### Typography
- Increase heading size for more impact
- Tighten letter-spacing on display text
- Use weight contrast more aggressively (thin body, bold headings)
- Break the grid with oversized type for focal points

### Spacing
- Increase white space around focal elements
- Use asymmetric spacing for visual tension
- Push margins and padding to create breathing room

### Motion
- Add entrance animations that build anticipation
- Use staggered reveals for lists and grids
- Add micro-interactions on hover and click
- Make transitions more pronounced

### Composition
- Create a clear visual hierarchy with one dominant element
- Use scale contrast (one large element among smaller ones)
- Break symmetry deliberately
- Add depth through elevation or layering

## Rules
- Amplify within the existing design system. Do not create a new one.
- One focal point. If everything is bold, nothing is.
- Bolder means more committed, not more cluttered.
- Preserve accessibility (contrast, touch targets, screen readers).
- Ship code, not concepts.
